一个网页，
教会你什么是网页。

不需要任何基础。你正在看的这一页，本身就是教材：读到哪里，就拆开它看看哪里。后半部分会带你打开浏览器里藏着的「开发者工具」（按 F12），亲手看到网页的骨架、对话框和它在网上收发的每一个包裹。

⏱ 大约 40 分钟 💻 建议用电脑上的 Chrome / Edge / Firefox 打开 🧪 每一节都有动手任务

1网页到底是什么？

一句话：网页就是一份「文字文件」，浏览器负责把它画成你看到的样子。

你可能以为网页是一张「图片」，或者是一种很神秘的东西。其实它比你想的朴素得多：网页本质上是一段写好的文字，里面用约定好的符号写着「这里是标题」「这里放一张图」「这个按钮是红色的」。

📄 → 🖥️
打个比方：乐谱和钢琴

网页文件就像乐谱，只是纸上的符号；浏览器就像钢琴家，照着乐谱弹出好听的音乐。同一份乐谱，不同钢琴家弹出来会略有不同——这也是为什么同一个网页在不同浏览器里偶尔长得不一样。

🏪 ↔ 🧑
网页从哪里来？

网页文件存放在世界某处一直开着的电脑上，这种电脑叫服务器。你用的浏览器叫客户端。你打开网页 = 浏览器去服务器那里「要」一份文件，服务器「给」它。

🧪 动手任务：看看这一页的「原文」
  1. 在这页空白处点鼠标右键，选择「查看网页源代码」（或按 Ctrl+U，Mac 上是 ⌘+⌥+U）。
  2. 会打开一个新标签页，里面全是文字和尖括号——这就是你正在看的这个网页的本来面目。
  3. 按 Ctrl+F 搜索「乐谱和钢琴」，你会在里面找到上面那段话。

看不懂没关系！你只需要确认一件事：网页确实就是一段文字。

💡 网页、网站、浏览器、互联网，有啥区别？ 网页是一页；网站是一堆相关网页的集合（比如一个购物网站有首页、商品页、购物车页）；浏览器是用来看网页的软件（Chrome、Edge、Safari、Firefox）；互联网是把全世界电脑连在一起的那张大网，网页只是在网上跑的众多东西之一（微信消息、网络游戏也在网上跑）。

3按下回车之后，发生了什么？

从你敲回车，到网页出现在眼前，通常只用不到一秒。我们放慢 100 倍来看。

⌨️
① 你输入网址，按下回车浏览器拿到了「门牌号」。
📒
② 查电话簿（DNS）浏览器问 DNS 服务器：「www.example.com 的数字地址是多少？」得到类似 93.184.215.14 的 IP 地址。
🤝
③ 建立连接浏览器和服务器「握手」，如果是 https 还要商量好加密的暗号。
📨
④ 发送请求（Request）「你好，我要 /shop/shoes.html 这个文件。我是 Chrome 浏览器，我能看懂中文。」
📦
⑤ 服务器回复（Response）「状态 200，没问题，给你！」然后把 HTML 文件发回来。如果找不到文件，就回复著名的 404。
🔁
⑥ 浏览器读 HTML，发现还要别的东西「这里要一张图片、一个样式文件、一个脚本……」于是再发出好多个请求。一个网页往往要几十上百个请求！
🎨
⑦ 画出网页浏览器把骨架（HTML）+ 衣服（CSS）组合好，画到屏幕上，再运行动作（JavaScript），网页就能点、能动了。
📌 记住这两个词：请求（Request）和响应（Response） 整个互联网上的网页，就是在不停地「一问一答」。待会儿在 F12 的网络（Network）面板里，你能亲眼看到每一次「问」和「答」。

4网页三兄弟：HTML、CSS、JavaScript

几乎所有网页，都由这三种东西组成。用「人」来比喻最好记。

🦴

HTML 骨架

决定网页上有什么：标题、段落、图片、按钮、链接。它用 <标签> 把内容包起来。

👗

CSS 衣服

决定网页长什么样：颜色、字体、大小、位置、圆角、阴影、动画。

💃

JavaScript 动作

决定网页能做什么：点按钮会怎样、自动刷新消息、表单检查、小游戏。简称 JS。

HTML 标签：网页的「积木块」

HTML 里每块内容都用一对标签包起来：<开始>内容</结束>。最常见的几个：

标签意思例子
<h1>～<h6>标题，h1 最大<h1>我的博客</h1>
<p>段落（paragraph）<p>今天天气很好。</p>
<a>链接，href 写要去的地址<a href="https://...">点我</a>
<img>图片，不需要结束标签<img src="cat.png">
<button>按钮<button>提交</button>
<div>一个「盒子」，用来把东西分组<div>...</div>

标签里的 src、href、class 这些叫属性，是对这块积木的补充说明。

🚨 安全警告：永远不要往控制台里粘贴陌生人给你的代码 骗子常说「在 F12 控制台粘贴这段代码，就能领红包 / 看到谁屏蔽了你 / 免费开会员」。真相是：那段代码会以你的身份在当前网站上执行，可能偷走你的登录状态、替你发消息或转账。这叫「Self-XSS（自我跨站脚本攻击）」。所以 Chrome 第一次粘贴时会要求你手动输入 allow pasting 才放行——它在保护你。自己理解的代码才运行。

9网络（Network）：偷看网页收发的每个包裹

还记得第 3 节的「请求」和「响应」吗？Network 面板把每一次请求都列成一行，一个都不漏。

🧪 任务 1：看一个网页加载时的全部请求
  1. 打开开发者工具，点「网络 / Network」标签。
  2. 此时列表可能是空的——因为 Network 只记录打开它之后发生的请求。
  3. 按 F5 刷新网页。列表瞬间填满：第一行通常就是这个 HTML 文件本身，然后是图片等。
🧪 任务 2：自己制造请求

保持 Network 面板打开，点下面的按钮，看新出现的行：

名称 Name状态 Status类型 Type大小 Size时间 Time瀑布 Waterfall
（这是镜像表，点按钮后会同步显示；真正的 Network 面板里信息更全）

每一列是什么意思

列含义
名称 Name请求的文件名或地址。
状态 Status服务器回复的「状态码」，见下表。红色表示失败。
类型 Typedocument 网页本身、stylesheet CSS、script JS、img / svg 图片、fetch/xhr 网页用 JS 要的数据、font 字体。
大小 Size传输了多少数据。显示 (disk cache) / (memory cache) 表示没去服务器，直接用了浏览器之前存下的副本（缓存）。
时间 Time从发出请求到收完回复用了多久。ms 是毫秒，1000ms = 1 秒。
瀑布 Waterfall时间线。条越长越慢；能看出哪些请求在排队、哪些是同时进行的。

状态码：服务器的「回话暗号」

开头大意常见例子
2xx成功 ✅200 OK 一切正常
3xx请去别处 / 用你手上的 ↪301 永久搬家了；304 Not Modified 文件没变，用你缓存的那份
4xx你（客户端）的问题 🙅404 找不到；403 没权限；401 请先登录；429 请求太频繁
5xx服务器的问题 🔥500 服务器内部出错；502/503 服务器暂时扛不住

点开一行，看「包裹」里面

在 Network 里点击任意一行（比如刚才的 data.json），右边会展开详情：

Headers 标头

包裹外面贴的「快递单」：请求地址、方法（GET 是拿、POST 是交）、状态码、浏览器自我介绍（User-Agent）、服务器说文件是什么类型（Content-Type）等。

Preview 预览

把回复内容整理成好看的样子，比如 JSON 数据会变成可折叠的树、图片直接显示。

Response 响应

服务器回复的原始内容，一个字不改。

Timing 时间

这一个请求的时间被花在哪里：排队、查 DNS、连接、等服务器、下载……

Offline 离线假装断网。
筛选栏 All / Fetch/XHR / JS / CSS / Img…只看某一类请求。
🚫 清空 / ⏺ 红点清空列表 / 暂停录制。
🔒 看到 file:// 开头的地址？ 如果你是直接双击 HTML 文件打开本页的，「请求数据」按钮可能会失败（浏览器出于安全考虑，不让本地文件随便读别的文件）。这本身也是一节课：去 Console 和 Network 看看红字是怎么说的。放到网上（比如 GitHub Pages）就正常了。

  2. 点击下面的按钮。网页会「冻住」，开发者工具自动跳到 Sources，高亮停住的那一行。
  3. 把鼠标悬停在 price、count 这些单词上，会显示它们此刻的值。右侧「Scope 作用域」里也能看到。
  4. 按 F10（单步）一行一行往下走，或者按 F8 / ▶ 按钮继续运行。

不用 debugger 也行：在 Sources 里打开文件，点击代码左边的行号，出现蓝色标记就是一个断点；再点一下取消。

11应用（Application）：网页在你电脑里存了什么

网页能在你的浏览器里存一些小东西，下次打开还记得你。Firefox 里这个面板叫「存储（Storage）」。

🍪 Cookie

小纸条，每次请求都会自动带给服务器。最常用来记住「你已登录」。

📦 Local Storage

本地储物柜，关掉浏览器也还在。常用来记设置，比如深色模式。

🗒 Session Storage

临时便签，关掉这个标签页就没了。

🧪 任务：让网页记住你
  1. 输入名字，点「存起来」，然后刷新网页——它还认识你！
  2. 打开开发者工具 →「应用 / Application」→ 左边「Storage」下的 Local Storage → 点开本网站地址。
  3. 你会看到一行 visitorName，值就是你的名字。双击值改成别的，再刷新网页看看。
  4. Cookies 下面也有一条 visited_lesson，是这个网页给你留的小纸条。
🧹 「清除缓存和 Cookie」到底清了什么？ 就是清掉这里的东西。清完之后网站会忘记你（需要重新登录、设置恢复默认）。在 Application 左侧「Storage / 存储」页里，点 Clear site data 可以只清当前这一个网站。

12还有这些好用的：设备模式、性能、体检

📱 设备模式：在电脑上假装是手机

开发者工具左上角，选择工具旁边有个手机+平板图标（快捷键 Ctrl+Shift+M，Mac：⌘+⇧+M）。点它，网页就会变成手机屏幕大小。顶部可以选具体机型、旋转屏幕。现在就试试：这个网页在手机上左边目录会消失，排版变成单列。这种「自动适应屏幕」的设计叫响应式设计。

⚡ 性能（Performance）：网页为什么卡

点圆形的 ⏺ 录制按钮，在网页上操作几秒（比如上下滚动），再点停止。你会得到一张详细的时间图，显示每一毫秒浏览器在忙什么：运行脚本（黄色）、计算样式和布局（紫色）、绘制画面（绿色）。看不懂很正常——知道「卡顿可以被录下来分析」就够了。

录制 Performance 时点它，会看到一大块黄色。

🩺 Lighthouse：一键体检

在开发者工具顶部找到 Lighthouse（可能藏在 » 里）。点「Analyze page load（分析网页加载）」，它会给网页的性能、无障碍、最佳实践、SEO（搜索引擎友好度）打分（0～100），并告诉你怎么改进。给你常去的网站测测看！

🔎 万能搜索：命令菜单

在开发者工具里按 Ctrl+Shift+P（Mac：⌘+⇧+P），可以搜索任何功能。比如输入 screenshot 选「Capture full size screenshot」，就能截下整个长网页；输入 dark 可以模拟深色模式。

14名词小抄

名词一句话解释
浏览器 Browser看网页的软件，负责下载并「画出」网页。
服务器 Server存放网页、回应请求的电脑。
URL / 网址网上某个资源的地址。
域名 Domain好记的服务器名字，如 example.com。
DNS互联网的电话簿，把域名翻译成 IP 地址。
HTTP / HTTPS浏览器和服务器说话的规则；HTTPS 是加密版。
请求 / 响应浏览器「要」东西 / 服务器「给」东西。
状态码服务器回复的三位数暗号，如 200、404、500。
HTML网页的骨架和内容。
CSS网页的外观样式。
JavaScript (JS)让网页能动、能交互的编程语言。
标签 / 元素HTML 里的积木块，如 <p>、<img>。
DOM浏览器根据 HTML 在内存里搭出的那棵「元素树」，JS 改它，页面就跟着变。
JSON一种常见的数据格式，长得像 {"名字": "小橙"}。
缓存 Cache浏览器存下的文件副本，下次不用再下载。
Cookie / Local Storage网页存在你浏览器里的小数据。
断点 Breakpoint让代码在某一行暂停，方便检查。
响应式设计网页自动适应电脑、平板、手机等不同屏幕。
